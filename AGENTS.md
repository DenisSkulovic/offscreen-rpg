# Offscreen RPG | agent entry

**Start:** identify actual repository, integration branch, HEAD, scope, permissions and existing work. Read current applicable instructions; memory is not evidence. Product docs own intended behavior, technical docs own guarantees, code/tests/evidence show realization.

**Submission standard (all agents):** [Design and Change artifact quality](.agents/references/planning-artifact-quality.md). Designs resolve coherent problems; Changes deliver exactly one measurable outcome. Delegated Change: normally 5–10 minutes active Cursor work, 1–5 tasks, **maximum seven actual tasks including every nested assignment**. Excessive size or scope requires consolidation, simplification or repartition before commission. Edit current statements in place, not amendment logs. Independent reviewers reject incoherent, oversized unjustified or unbounded submissions before technical review.

## Design before packets (owner decision 2026-11-26)

Material architecture, infrastructure or domain renewal follows [design-led engineering](.agents/rules/target-driven-renewal.md): choose posture, research alternatives and pinned upstream/source evidence, make specimens and discriminating experiments, settle safety/integration/acceptance, defend coherent target. A redesign request authorizes scoped non-destructive design investigation; start substantive work in the same turn. Respect selected clean-slate exclusions until target is coherent; preserve adjacent contracts/data. No implied implementation, live mutation or spend.

After self-defense require a fresh-chat [independent architecture committee](.agents/rules/target-driven-renewal.md#mandatory-independent-design-committee) before owner acceptance and promotion. Apply submission gate, commit every verdict (including rejection/consultation) on reviewed design branch and verify push. Chat-only verdict is incomplete. Promote accepted target into canonical owners before implementation commission; choose direct planner implementation, bounded Cursor Changes or hybrid. No artificial Design for small settled fixes.

## Dependency readiness is not a planner blocker

Fully settled work may be Ready (dependency-gated) before predecessors land. Explicitly commissioned tasks may dispatch after verified prerequisite receipts and source postconditions; mechanical reconciliation allowed, architecture invention not. PLANNER-BLOCKED means named material decision/authority/safety/source/semantic contradiction or failed submission gate, not ordinary dependency order or separately owned heavy proof. Verify commission, source and push before dispatch. Continue authorized scope through checkpoints until completion, genuine blocker, necessary owner check or permission boundary.

## Mandatory implementation boundary

**Git:** main is the current integration trunk; verify recorded target including explicitly authorized alternative. Storyteller Workshop is a dossier, not second trunk. No new joins to old branch; preserve in-flight work and do not force-push/delete old branch before verified migration. Dedicated `change/<id>-<slug>` branch and separate linked worktree per commissioned implementation Change, never switch primary checkout or discard existing work. Parent runs `node scripts/repo-tools/change-branch-guard.mjs --change <ID> --target <reference-branch>` inside assigned worktree. No per-T-ID branch; shared-checkout children do not stage/commit. [Branch policy](.agents/references/bounded-parent-orchestration.md#mandatory-change-branch-policy).

**Planner:** [product](docs/product/README.md), [technical](docs/technical/README.md), [evidence](evidence/README.md). Verify current source, owners, callers, schemas, permissions, failure/replay, tests and migration map. Follow [Change standard](.agents/references/change-work-unit-standard.md), [packet design](.agents/references/packet-design-manual.md), [submission standard](.agents/references/planning-artifact-quality.md) and [readiness review](.agents/references/packet-readiness-review.md) before Ready. Unresolved architecture stays with planner; no Cursor discovery disguised as PATCH. Reconcile docs at closure; no pointless pre-code rewrite for settled details.

**Execution/acceptance:** Cursor implements selected Change, constructs specified deterministic proof tools, runs focused unit/contract, changed-file quality and cheap local integration checks. ChatGPT + owner own broad builds/suites, infrastructure lifecycle/fault recovery, multi-service/browser/end-to-end, release upgrades and long/costly probes. Planner specifies exact target, commands, prerequisites, positive/negative predicates, deadlines, cleanup/stop and evidence; owner runs authorized batch and planner interprets. No heavy proof by Cursor unless explicitly delegated by name. Essential cheap negative tests remain required.

At source completion parent commits exact SHA, paths, tests, known failures, remaining acceptance and resource/collision state. If heavy acceptance pending, stop **IMPLEMENTED — ACCEPTANCE PENDING**, retain branch/worktree, no merge/archive/retirement. ChatGPT/owner certify exact SHA, route defects to bounded follow-up; custodian reconciles main drift, integrates after proof. Cheap-only Changes close autonomously when all gates pass; no ceremonial extra approval, no auto-next. [Parent procedure](.agents/references/bounded-parent-orchestration.md) · [verification](WORKFLOW.md#9-verification-review-and-the-next-loop).

**Quality and authority:** [Code craftsmanship](.agents/rules/code-quality.md), changed-file formatting/lint, focused positive/negative tests, actual diff. Preserve authentication, permissions, data integrity, idempotency, financial/provider-spend safeguards. Read-only and authorized disposable checks are not permission for paid calls, protected database writes, deployments, destructive operations or secrets. Escalate architectural contradictions with file/symbol/reproducer. PASS, NOT RUN, source-inspected and live-observed are distinct. [Budget](.agents/references/cursor-model-budget-policy.md) · [documentation](.agents/rules/documentation.md) · [spending](.agents/rules/spending.md). Source health: `pnpm repo:code-health`, compare reference with --base, newly crossed severe bands --strict-new; numeric hot spots trigger review, not automatic refactor.

**Dev resources:** Change/worktree does not require running stack. Verify current commands/prerequisites in [owned dev stacks](docs/runbooks/dev-worktree-stacks.md) and [environment contract](docs/technical/platform/developer-environments.md). Source-only first; acquire only needed capacity, never bypass admission/seize foreign environment. On partial startup/pressure/OOM park only own attempted workloads; preserve reservations and SQL/S3/Temporal tenants; confirm own replicas/processes/ports parked, report contention/back off. Never kill foreign processes/remove release or infer tenant destruction authority from stopped process. Registry/lease state machine-local, not Git evidence. Tilt sole active dev Deployment image writer. No invented commands or stale status.

**Parallel work:** separately authorized Changes with disjoint writes/resources; one custodian serializes shared docs, queue/status, migrations and final joins. [Parallel policy](.agents/references/change-work-unit-standard.md#batch-execution-and-parallel-change-orchestration-2026-11-19).

**Lifecycle:** [Design catalog](work/designs/README.md) and [Change catalog](work/changes/README.md) own open/backlog/archive routing. Active decisions/outcomes open; deferred worthwhile work backlog with trigger; terminal archive provenance, not authority or selection. Promote accepted meaning, preserve unique evidence, repair links and ledger with full SHA/path. Seven-day archive review is not deletion authorization. Never retire or mark Done with mandatory proof pending. [Commit format](.agents/rules/git-commits.md) · [maintenance](REPOSITORY-STRUCTURE.md).

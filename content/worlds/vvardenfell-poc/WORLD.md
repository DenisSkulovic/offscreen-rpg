# Vvardenfell arrival reference

This bounded reference supports the first Offscreen RPG proof: a released
prisoner arriving at Seyda Neen on Vvardenfell. It is not a complete setting
encyclopedia. Treat facts outside these pages as unknown or as explicitly
labelled Storyteller interpretation rather than silently relying on model
memory.

The immediate playable area is Seyda Neen, a small Imperial port and census
settlement in the Bitter Coast marshes. The northbound road eventually leads
toward Balmora. Imperial administration, local Dunmer culture, dangerous
marshland and distant volcanic pressure can all matter, but the current scene
should load only the focused pages it needs.

## Operational contract

1. **Open** is only for work with a named unresolved decision, owner, next action and review deadline. A design linked to a finished Change is not automatically still open.
2. On acceptance, write outcomes into the permanent wiki and actual implementation Changes. On rejection, deferment, cancellation, supersession or completion, record one concise entry here, including a **full commit SHA** and exact original path. Preserve dissent/negative evidence by linking the immutable source.
3. Move terminal dossiers into the browsable [archive](../archive/README.md); move deferred worthwhile investigations to [backlog](../backlog/README.md). Review archive retention after seven days by default, then prune only with explicit authorization and link/owner/uniqueness reconciliation. Git is permanent recovery. No age-only retirement.
4. Replace active-tree inbound references with canonical wiki links (normative) or **historical Git snapshot URLs** (research/receipts) before removing a folder. No silent broken links; do not rewrite dated evidence as current spec.
5. A worthwhile unratified proposal can be marked **Deferred** and moved to backlog. It is **not rejected**, nor does archiving adopt it; a future owner can reopen only through a new current source audit and decision.
6. Changes use `work/changes/ledger/` and the same Git-first eventual pruning. Archive is a **short-lived review cache**, not permanent ownership.

## Selected constraints (unchanged)

[Spatial continuity](../../../../docs/product/gameplay/continuity.md#space-movement-and-maps), [scene/place distinction](../../../../docs/product/gameplay/continuity.md#places-scenes-and-cinematic-presentation), [travel duration and progress](../../../../docs/product/gameplay/time-and-autonomy.md#travel-duration-and-progress), [calendar authority](../../../../docs/technical/engine/calendars-and-world-time.md#calendars-label-accepted-time) and [spatial storage boundary](../../../../docs/technical/platform/data-and-persistence.md#spatial-model-boundary) own selected meaning. Established whereabouts and interrupted progress must survive narration, view changes and restart. Explicit exceptional transitions cannot silently repair contradictory prose. A view change does not relocate another actor or erase their surroundings. Distinguish fictional duration from real waiting, paused time and calendar labels. Narrative location, mechanically admitted movement and executable topology are different things; no universal geography, metric distance, grid, straight-line interpolation, route planner or mandatory map.

## Seven unresolved decisions

| Question | Alternatives / boundary |
| --- | --- |
| Distance source | Authored connection, metric geometry, discrete transition or nonmetric relation; local estimates are not engine defaults. |
| Visibility | Character-scoped knowledge versus retained world facts and optional drawings; no selected visibility mechanic. |
| Map identity | Stable identity/revision and local-region relation; descriptive documents, media and topology differ. |
| Travel ETA | Derivation, display and invalidation; a captured duration is not a computed ETA, pace changes real wait only. |
| Teleportation | Explicit admission, skipped progress, invalidated planned arrivals and commitments. |
| Concurrent position | Multiple actors' compatible circumstances at the same fictional time; proximity/rescue and shared-play consent remain later scope. |
| World clock | Admitted progress, deadlines, pause and calendar projection; no movement formula selected. |

Compare named places, discrete transitions, route graphs and metric geometry against the smallest representation sufficient for interrupted journeys. Test departure without arrival, partial progress, restart, pause and pace change, route invalidation, explicit exceptional transition, hidden geography, a second actor remaining behind, and a bodiless nonmetric world. A route described in lore cannot grant executable movement. Different terrain, stationary waiting and portals falsify universal linear interpolation. Preserve accepted consent, source identity, exact state and time authority; no historic map geometry selected.

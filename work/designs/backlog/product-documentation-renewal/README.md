2. Inventory headings and claims by selected, conditional, proposed, illustrative and observed status. Examine overlapping vision/concepts/rules/time/continuity/Storyteller/acceptance narratives. Distinguish actual contradictions from hypotheses.
3. Preserve consent, authoritative mechanics, no duplicate effects, choice/absence semantics, historical forks, privacy, financial and staff boundaries. Preserve useful imaginative scenarios while labeling assumptions; no arbitrary compression or uniform page templates.
4. Produce a small before/after specimen and claim-preservation map for owner review. Define practical reading routes and file roles; coordinate dependencies with [technical renewal](../technical-documentation-renewal/README.md).
5. Reconsider scope by domain if workshop expands. Only after review and owner acceptance select direct editorial work or bounded documentation Changes.

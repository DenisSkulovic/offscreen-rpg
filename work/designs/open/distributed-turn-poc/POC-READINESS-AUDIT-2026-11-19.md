## Highest-value findings

**F1 · Authority is distributed in *deployment vocabulary*, not yet in the story mutation path.** In `apps/api/src/modules/stories/controller.ts`, `startFromCandidate` and `fork` still call local `this.stories`; `admitResolution` uses the remote seam. The GA server only declares read/admit-resolution routes. A complete turn cannot be called one-writer distributed if Nest can still mutate the same scene outside GA while a GA Pod is running. **Design decision:** use the existing product/application logic, but route the *POC's selected story writes* through GA's authenticated, versioned private transport. Preserve Compose as an explicit fallback, never a silent fallback in distributed mode. Stronger SQL privilege separation can follow as a targeted security hardening; until verified, call the boundary a software routing boundary, not database-enforced isolation.

**F2 · The orchestration break is precise.** `storytellerV1` has one `completeStoryteller` Activity with a three-minute timeout; `createStorytellerRuntime.complete` owns both provider execution and publication. Introduce a **new versioned workflow** with independently assigned tasks, not a silent semantic change to historical `storytellerV1` executions. Control/outbox process starts or wakes Temporal by direct RPC; executor gets a frozen task and returns a saved validated result; **only GA** validates current story/root and publishes with its own SQL transaction. A prior saved result must be read on replay, not regenerated.

**F3 · Scene data is further along than the plan language suggests.** Reuse the `scene-checkpoint.ts` hash/selector and staged-then-commit transaction pattern. The remaining proof is authoritative state + exact manifest root in the same *logical* scene, historical as-of read and independent fork, across real S3 and SQL failure boundaries. Reject a missing object; never quietly read latest.

**F4 · Fake-provider proof and real-model proof are two separate milestones.** A fake response tests admission, retries, routing, persistence and UI. It does **not** test whether the Storyteller DM actually interprets the campaign or produces a useful scene. Complete the fake gate before asking for a capped, single real run. The real run is part of the owner's ultimate goal but requires fresh opt-in spending authority.

**F5 · The Rabbit dependency contains a contradiction.** Ratified [D5](D5-RELEASE-AND-ACCEPTANCE.md) says RabbitMQ is only required **if** a separate postcommit consumer is selected; its lag/absence does not fail the turn. [TURN03](../../../changes/open/2026-11-19--turn03-full-distributed-forkable-turn-proof/CHANGE.md) and the queue still name the Rabbit projection in their required full-turn chain. **Decision:** first POC acceptance has a direct outbox→Temporal story chain. Broker projection is a **parallel optional demonstration** under DIST02/DIST04, never a story-availability prerequisite or source of scene truth. If separately selected, prove it without making TURN03 wait for an irrelevant consumer.

**F6 · Current packet lifecycle is not automatically wrong because a slice landed.** DIST03, BOOT02, DATA04, STORY02, WIKI18 and others show partial landed work. Demand the packet's negative proofs and a reconciled claim ledger; don't restart them from zero or archive incomplete outcomes to tidy the queue. Prefer completing *one* source-backed seam at a time.

## Failure probes that distinguish real progress from diagram theater

1. **Multiple writers:** with distributed mode on, intentionally make a formerly local write route (start, fork, publication) from Nest. It must use the GA transport or fail closed, never silently write through Nest. With Compose mode, existing direct path remains.
2. **Crash window:** fake provider result is saved; kill Storyteller executor before publication. Restart must reuse the same saved result and generate exactly one passage/checkpoint; no second provider invocation.
3. **Stale root:** parent advances between task capture and result. GA must refuse the stale proposal rather than publish an out-of-branch canon root.
4. **Object store:** stage succeeds then SQL aborts; staged object is unreachable. Referenced object missing on historical read must fail, not produce a fabricated older state.
5. **Messaging:** Temporal unavailable leaves outbox pending/retriable with bounded errors. Rabbit unavailable cannot block start, publication or GET. Duplicate optional Rabbit event may update a projection at most once.
6. **Browser:** dropped SSE hint does not resend the command. GET after refresh resolves committed scene. Wrong owner denied for scene, historical view and fork.
7. **Deployment:** boot all real images simultaneously in cold kind, record memory and digests; demonstrate authentication and private network routing. Placeholder Ready is fail.
8. **Real-model truth:** scripted test receipt has `provider_mode=fake` (or equivalent source-backed evidence); only an authorized actual provider response may be labeled live. Uncertain send cannot automatically retry.

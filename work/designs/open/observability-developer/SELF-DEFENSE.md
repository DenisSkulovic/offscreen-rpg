## Findings and dispositions
SD01 Necessity: original design deliberately excludes actual producer enrollment; Pod-IP listener refused port-forward, synthetic OTLP accepted but query helper crashed. Existing five-release foundation worth preserving. Defended evolutionary direction. Reject wholesale replacement and unrestricted original receiver.
SD02 Native Helm and layout: actual chart render and binary validation of dual receiver with strict filters PASS; custom hostPort null rejected and corrected to omitted. Four resource identities unchanged. Defended topology and no wrapper chart. D0 reference census partial; full tracked census required for implementation.
SD03 Trust: receiver separation is not authentication; any network client able to reach backend may bypass filters. Trusted local owner and synthetic-only qualification are explicit; no adversarial confidentiality, no production exposure. Defended bounded local trust posture only. Reject universal secret-detection claim. No actual SDK or release enrollment in selected scope.
SD04 Metric identity: arbitrary removal of dimensions merges streams; instance attribute removal risks writer collisions. Revised target finite metric names, required single bounded label, single writer per series, no per-run IDs, reject extra attributes. Remaining decisive evidence: actual exact filter and transform syntax and behavior, malformed metric value/bucket treatment and Prometheus series identity including target_info. Generator is concrete candidate, not validated; currently does not enforce numeric value/bucket constraints (producer contract only until revised). Cannot claim target enforced by Collector. EVIDENCE-GATED.
SD05 Occupied transition: Helm list counts do not prove history; live config checksum alone can lie; exact relay match observed. R3 adds current/predecessor projection and strict history, full CA/identity, pending before mutation, one scoped upgrade with no auto rollback. Preserve claims and credentials. Guard completeness, current runtime projection, operation-specific lock and actual Helm successful history proof remain required. Design direction defensible; exact normalization and custody/session integration still needs source completion. EVIDENCE-GATED for final upgrade algorithm.
SD06 Failure and concurrency: shared receiver resources, exporter failure and restart may lose telemetry; explicitly best-effort, no business correctness dependency. Foreground session shared lock excludes upgrade, no reconnect, only owned child cancellation; parent SIGKILL orphan handling needs a concrete verified mechanism. Reject merely relying on Ctrl+C or broad PID scanning. EVIDENCE-GATED for lifecycle mechanics.
SD07 Test strategy: source green did not prevent real defects. Existing diagnostics retain their semantics and obligations. Real application-shaped synthetic probes and backend query positive controls distinguish 200 responses from data persistence; absence requires successful repeated query. Essential matrix explicit; no isolated cluster for ordinary qualification. Defended proof architecture, not execution.
SD08 Scope drift: P0/P1 currently no telemetry; do not block it on infra change or silently alter dossier. New shared instrumentation library not included. Defended.

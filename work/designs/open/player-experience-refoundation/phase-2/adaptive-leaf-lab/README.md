# Adaptive Leaf | Interactive design laboratory

**Status:** OPEN DESIGN / NOT RATIFIED (2026-11-17). **Implementation authorization: none.** The selected V1 presentation contract in `docs/technical/client/presentation-runtime.md` remains authoritative.

## Open the visual prototype

Download/open [index.html](index.html) in a browser. No npm, APIs, paid model, stored story, server or generated image required. The **top bar is a design-only control panel**, not game UI.

- **Direction:** Weathered, Translucent, Luminous or No Direction. These are *design fixture documents*, **not genre themes in production**. They supply normalized material/light/palette/typographic values to the **same DOM and rendering code**.
- **Content:** Greywater (identical exact source across appearance comparisons), Seventh Current (nonhuman form), Last Bus (quiet), Found Document (an actual in-fiction record embedded in the narrative).
- **View:** Now, Ongoing, Journal, original Reader, Ended, Branches. The buttons only navigate a self-contained mock.
- **Fallbacks:** Toggle the rich-text score, illustration slot, and ambient motion OFF. The original words and current authored options remain visible.

**Visual invariant:** the page/leaf is a recurring *reading structure*, not mandatory historical parchment. It accepts optional world-specific atmosphere, material, bounded emphasis and eventual source-approved art. Status, reader navigation, offer authorization and story history remain platform-owned. There are no conditional `SpacePage` or `CavePage` renderers.

## Important unimplemented boundaries

This is neither a new `StorySnapshot` schema nor a production Storyteller/renderer. Its input objects are *illustrative art-direction documents*. No actual LLM chooses them, no user data is stored, and no trusted backend validation bridge exists. The inline rich marks are authored fixtures, **not** a versioned/source-hashed real score. Historical page appearance is not persisted. Fictional choices only show a nonfunctional notice.

The Journal's numeric 2,000-position control **is a synthetic design scale demonstration**, not a full-text index or seek endpoint. Unavailable positions explicitly show *not loaded*. Forking is illustrated as lineage, but the sample rejects arbitrary historical forks because the current game cannot reconstruct all historical state. A dramatic ending line is not authoritative campaign lifecycle.

## Durable triage rules for Cursor

1. **Delete:** unowned executable with no supported operational use and no live import/caller, after a direct source search and negative proof; use git history for recovery.
2. **Move/reclassify:** past investigations masquerading as *open* status, only with a complete backlink repair and no loss of one authoritative decision/evidence record. A doc-only move is not itself a code-bearing Change.
3. **Refactor:** monolithic code with a demonstrable ownership/test boundary, preserving every observable invariant, mock/provider rule, CLI exit code and negative test. Extract one seam per Change.
4. **Keep:** active migration snapshots, registered CI tools, light adapter wrappers, linked test fixtures/content, historical decisions and forensic evidence. “Old” does not mean disposable.
5. **Do not manufacture work:** deliberately excluded from this effort are a package-wide directory rename, engine/Storyteller prompt redesign, Play UI restyling, open UI01–UI08/DIR01–03 waves, arbitrary DB schema squashing, and the 2026-11-17 retrieval experiments already retired by HAR10.

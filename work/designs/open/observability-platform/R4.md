## Decisions
Trusted single-operator local clusters only. ClusterIP is not authentication; Loki/Tempo lack built-in auth (https://grafana.com/docs/loki/latest/operations/authentication/ and https://grafana.com/docs/tempo/latest/operations/authentication/). No external service, ingress or public port. Grafana authenticated loopback port-forward; backend read/write not protected against other cluster workloads, no hostile slot isolation. CNI enforcement not assumed (https://kind.sigs.k8s.io/docs/user/configuration/). Initial actual live experiment must be an explicitly authorized isolated synthetic-only cluster or otherwise proven isolated workload set; occupied dev/release installation is NOT authorized by this decision. No real application enrollment. No sensitive content in initial fixture even for negative tests: use fake canaries only. Source allowlisting plus collector filter/transform before app adoption, not arbitrary regex sanitation. See https://opentelemetry.io/docs/security/config-best-practices/ and https://opentelemetry.io/docs/collector/transforming-telemetry/ . Filter names/values/body/resource/scope/events/links/exemplars as applicable; fail closed for unknown signal schemas; no claim that key allowlist alone prevents leakage. R3 specimen lacks admission and is render-only.
Lifecycle candidate: explicit profile/context and ownership admission using common commands.mjs assertPlatformTarget (line 285 at main), bounded runPlatformCommand, existing host memory gate (4096 MiB minimum; not enough to prove capacity of this stack). Before any write classify entire bundle (namespace, releases, resources and PVCs, legacy lab-a collector); exact rendered inventory needed. Absent -> explicitly authorized install; complete matching -> read-only no-op; partial/foreign/unreadable/legacy -> refuse. Install deterministic Prometheus,Loki,Tempo,Collector,Grafana order; separate namespace/secret ownership preflight; stop on first failure and retain evidence/data, no blind uninstall or automatic repair. Recheck identities before each write, serialize concurrent owned operations; actual shared lock contract and partial recovery design pending. Never delete shared lab-a. Status structural only, separate signal query smoke. Full configuration drift attestation not established. Additional seam: common/render.mjs RELEASE_ONLY_SERVICES and platform service set, allowedNamespacesForService and chart routing; diagnostic.mjs source tests and PL-06 service registration. Inspect remaining callers before defense.
## Experiment E01
Run experiments/render.sh with bash from immutable design checkout. Requires Helm, curl, timeout, sha256sum, Python3 and PyYAML; no automatic installation. Downloads five candidate archives to private unique temp directory, verifies GitHub-published SHA256, renders dev/release with explicit storage overlays and kube 1.37.0. No kubectl/Docker/helm install, no live state, no credentials. Render is local but requires outbound HTTPS downloads. Each attempt has bounded curl and render timeout. Save error and manifest files; report results.tsv and inventory.txt; inspect errors on failure. No automatic cleanup; owner can remove exact evidence directory after review. Inventory highlights host access, host ports, public service, secret, RBAC/route and CRD; not a complete security validator. Rendered config and exact image refs require further audit; image digest resolution and binary validation next. Script has not been executed against real archives. No live or design acceptance credit. 
Expected: 10 successful render records, 5 primary workload roles per profile, exactly three retained backend PVC requests, ClusterIP only, no unexpected hooks/sidecars/privileged/RBAC/CRDs, fixed service addresses, no generated Secret (Grafana expects separately owned Secret). Any discrepancy is evidence to revise, not permission to override upstream validation. A successful render does not prove binary config or runtime behavior.

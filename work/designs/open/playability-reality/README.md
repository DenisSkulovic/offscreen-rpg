# REAL | Make one fictional life genuinely playable

**Status:** designed investigation and proposed scoped Changes, **not** a second product authority. Reviewed at 2026-11-18 `main@3d673471dca6418c0dc6380199e913e00ae9ffb6`. This initiative is downstream of [Audit II](../product-reality-reconciliation/AUDIT-II-2026-11-18.md) and the already ratified solo-first decision (PVAL02). Reinspect HEAD when executing.

## End-state to prove

One human can start an authored solo life, make several meaningful decisions, accept an activity that continues without browser/model polling, be interrupted by a justified development, return to committed progress, and later encounter an identifiable person or promise that was preserved without inventing a transfer or fictional time. The experience must make the player want to continue **and** fit a measured provider budget. This is a **product hypothesis**, not an implemented/live-tested promise.

The game is not a universal Storyteller, agent framework, world simulator or lore-ingestion platform until that small thesis works. Preserve existing deterministic source authority, choices, clocks, receipts, versioning, consent, and narrow provider budget fences.

## What exists today vs what is missing

- **Source-observed:** finite actions, declared item transfer effect, admitted activity progress, current/narrative passage persistence, proposed document changes, versioned document publication, some bounded retrieval and provider usage accounting.
- **Fixture-tested:** separate descriptive materialization decisions; harbor session arithmetic; canonical staging tests. These components do **not** prove a reliable played memory lifecycle.
- **Unproved:** Storyteller spontaneously chooses the right enduring identities/relationships; a return after unrelated activity sees the exact right canonical evidence; multiple meaningful scenes remain enjoyable; offscreen return adds value rather than a waiting tax; aggregate cents per accepted *interesting* turn.
- **Known blockers/risk:** mechanical choices do not carry the narrative choice's optional document dependencies (S3 design, not landed); a documented live multi-round memory `budget.settle` continuation defect remains outside these packets; existing authored fantasy acceptance is not a first-solo oracle.

## How to use this register

Start with S0. For each later wave, open the latest source file, its governing product/technical owners, actual inbound headings, status/proof and any recent changes. Confirm whether the proposed action still fits. Mark each actual disposition (rewrite, split, surgical clarification, or justified no-op) in the **wave's editing receipt**, not in a second permanent status tracker. Do not “complete 70 edits” as a vanity metric. Protect correct pages from needless churn.

The most expensive failure would be a broad rewrite that reads cleanly but changes the meaning of active/accepted constraints. Independent review must compare a before/after claim ledger and counterexamples, especially time, spending, privacy, player choice and durable history.

## Binding specimen

One resolved workload objectStorage value (not a provider registry): bucket, region, optional endpoint, forcePathStyle boolean, credentials { mode: secret, secretName } or { mode: default-chain }. Preserve existing OFFSCREEN_DOCUMENT_S3_* env names. Local secret keys access-key-id and secret-access-key. Explicit true/false accepted by parser (existing true/1 and false/0 compatibility); omitted flag retains old endpoint-dependent default. Reject malformed flag and half credentials. AWS mode omits endpoint and explicit credential env, uses SDK chain; hosted service account identity and cloud provisioning not implemented. External custom endpoint must support HTTPS and provider addressing requirements. No proxy, externalName, CRD or generalized IAM driver. Provider installation choice belongs to environment composition, not workload schema.

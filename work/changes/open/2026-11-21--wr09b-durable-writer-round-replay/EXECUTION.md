# WR09B | selected replay/decision algorithm

**Gate 0: actual WR09A compatibility**. Read the integrated exports and P3B/WR09A receipt. Require strict custody returns (1) delivered with exact persisted result SHA and linked response-object pointer or can be read by step identity, (2) replay/uncertain/held distinct status, (3) readDurableWriterMissionResponse returns original bytes with no send, and (4) provider transport preflight is mandatory before possible send. Check actual TS symbols; a mismatch is planner-stop (do not redesign).

1. Keep existing runWriterMissionModelRound unchanged externally and existing scripted hash/unit behavior. Extract its **post-delivery** decision interpretation from parseProviderDecisionBody through final/tool/research-delegation result into a private interpretPersistedWriterDecision(database,{capture,missionId,contextId,ordinal,expectedRevision,access,reader,storage,body,resultSha256}). Both scripted and durable entrypoints call it. Preserve exact v3 final capture validation, existing acceptWriterSceneProposal handling for v1/v2, hold reasons, and tool grant checks.
2. New runDurableWriterMissionModelRound(database,input) input = same mission/context/ordinal/attemptId/expectedRevision/capture/access/reader/storage as scripted, plus policy:WriterRoundModelPolicy, expectedWireSha256:string, transport:PreparedWriterRoundTransport; no scriptedDecisionBody. Validate capture.version === writer-mission.v3 and modelSelection.model equals policy.model and captured model is **not** scripted-offline, and finite budgets/model rounds. Build/prepare pinned wire from existing prior tool summaries; expectedWireSha256 must equal exact build hash and stored step.requestCasHash, otherwise hold before provider spend.
3. Read SQL step first. If terminal result-settled, read WR09A CAS exact body by attemptId/requestSha, revalidate original hash, then pass it through shared interpreter. If tools-applied, inspect existing next model step (must be one valid prepared ordinal); return a resumable tool-round-complete/replayed marker without reexecuting tools or provider. If proposal-ready, re-read original response CAS and return validated final proposal (do not publish in this function). If dispatched/uncertain/held/failed, refuse provider invoke. Only first eligible non-dispatched preparation calls advanceDurableWriterMissionProviderStep with supplied prepared transport; after delivered ALWAYS retrieve bytes from private CAS and interpret **that**, not a separate in-memory response string.
4. Library tool idempotency: before each Library execute, SELECT existing storyteller_writer_step row with (missionId,contextId,toolCallId). If row exists, compare requestCasHash to hash of (tool name,args), verify state tools-applied and read/private-validate resultCasHash summary; append same summary without calling Library again. If no row, run read-only Library tool, persist private summary, INSERT tool receipt. On unique race, re-read the winner under SQL and compare requestSha, use winner result; never repeat Workdesk mutations through a new code path. Workdesk stage/read/discard remain delegated to existing executeWriterWorkdeskTool, which has its own idempotency. For child context keep current implementation/limitations unchanged; this Change is parent v3 only.
5. After all tools, **one SQL transaction** locks/re-checks matching parent model step/revision and changes state to tools-applied and inserts exactly one next prepared model step derived from the existing compiled prior summaries. If on retry parent already tools-applied, load/check that next step; do not insert. If another process raced, return conflict/replay and re-read; no forced rewrite or duplicated model step. Never do provider request/DocumentStore I/O while holding SQL locks.
6. On final, mark proposal-ready with matching expected revision and the exact already-settled raw response hash; after crash in that state rehydrate final proposal by reading same response CAS. A later caller can call existing publishAcceptedWriterScene under Game Authority's admitted story transaction; no direct Worker bypass added. Verify duplicate publication returns existing passage/checkpoint without extra narrative revision.
7. Max rounds: do not create ordinal beyond capture.budgets.maxModelRounds in a bounded parent; research.delegate returns dedicated join notice and does not recursively invoke the parent model on same call stack. If a capture lacks grant, hold ungranted_tool. Preserve private Workdesk visibility, source-root checks and rejected fabricated sources; do not turn malformed provider response into free cost or automatic retry.

**One-round source truth:** CAS response is the durable decision. Tool receipt rows are the durable action ledger. Parent step revision+next model ordinal is the durable continuation. Do not add a fourth alternate mission state table.

**No real provider call:** tests construct PreparedWriterRoundTransport with injected fetch that never uses network, and local disposable SQL/object store. No Worker env/secret startup or player API path in this Change. The real end-user Writer routing/launch remains a separate subsequent implementation, explicitly acknowledged rather than falsely certified.

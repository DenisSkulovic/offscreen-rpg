Current contract sections below are the proposed narrow mechanism; no old packet precedence chain. No live mutation or compatibility bypass.

Keep public captureIdentity(profileId,contextName,deps) and recheckIdentity(identity,deps). Add runObservabilityReadCommand(command,args,{input,timeoutMs=15000}={}) using spawnSync shell:false, detached:false, encoding utf8, killSignal SIGKILL, maxBuffer 8MiB, no inherited stdin. Reject nonpositive/expired timeout; result existing {ok,status,stdout,stderr,timedOut,missing}, ETIMEDOUT and ENOENT explicit, no usable partial output on error. Adapter accepts positive integer timeoutMs<=60000, default15000; identity callers clamp to min(15000,floor(remaining)); inventory (D04) to min(10000,remaining); offline Helm template only to min(60000,remaining). Do not globally impose the identity cap on template. Check monotonic before/after; no 1ms fallback or late success. Trusted direct binaries only, not arbitrary descendant containment. Capture/recheck 210s each; selected F08 outer allocations below, pending independent ratification.

Keep common commands.mjs::assertPlatformTarget unchanged for unrelated platforms. Its dev baseline owner key is profile.ownerLabel + '/owner' (offscreen.dev/owner) and value DEV_CLUSTER_OWNER; release baseline is RELEASE_BASELINE_NAMESPACE, key profile.ownerLabel + '/lab' (offscreen.rpg/lab), value profile.ownerValue. Target namespace owner label is profile.ownerLabel itself (not either baseline suffix). Reuse these imports/constants. Common guard is an ambient pre-admission check only; wrap its run callback in the same bounded deadline adapter, including its implicit default-timeout calls. No new common guard option or global behavior change.

Refuse nonempty KUBECONFIG, DOCKER_HOST/CONTEXT/TLS_VERIFY and all HELM_KUBE* overrides, HELM_DRIVER except absent/secret. Also refuse Docker certificate-path/TLS overrides that could redirect local trust (DOCKER_CERT_PATH, DOCKER_TLS); no arbitrary inherited Helm driver. Read selected current-context and require profile.contextName. Run common guard (three commands), then raw flattened minified selected config JSON. Require exactly one context, referenced cluster and referenced user (not merely users[0]); names and selected current-context agree, explicit loopback HTTPS and profile port, nonempty inline decoded CA, client certificate/key; reject exec/auth-provider, proxy-url, insecure TLS, external credential/CA file paths, token/auth overrides. Read Docker context show, inspect that context Host, then inspect exact control-plane container; require local allowed endpoint, running, exact cluster/role labels, unique matching loopback published port and nonempty container ID. Record dockerContext in tuple in addition to dockerEndpointHost (prevents same-endpoint context drift); do not persist cert/key bytes.

Create private snapshot before any further Kubernetes API read: mkdtemp owner-private directory, or explicitly supplied test root verified owner/private/non-symlink; open snapshot.json O_WRONLY|O_CREAT|O_EXCL|O_NOFOLLOW mode0600, write exact serialized raw config bytes, fsync, close, lstat verify regular file, owner, nlink=1, mode0600. Require exit0 and clean stderr, exact kind/name, nonempty UID, nonterminating; only empty successful stdout means absent. kube-system and baseline must exist; baseline owner exact and UID equals common pre-admission UID. Target may be absent; if present require UID, nonterminating and exact namespace name, leave target owner/legacy determination to inventory classifier (do not hide occupied legacy as absent). Tuple {profileId,contextName,clusterName,port,dockerContext,dockerControlPlaneId,dockerEndpointHost,caSha256,kubeSystemUid,baselineUid,targetNamespaceUid}. Server derived exactly from loopback+port. No raw config output. On capture error remove only known private snapshot after identity check, no recursive removal of replaced directories or foreign files. cleanup idempotent returns same first outcome, verifies path/inode/owner, unlinks only owned snapshot, rmdir only owned empty generated directory; supplied root never removed. Report retained private path on cleanup failure without dumping contents.


## Recheck and namespace create
Recheck sequence: validate environment and private snapshot dir/file identity/hash first; require supplied expectedNamespaceUid if present equals identity.tuple.targetNamespaceUid (never override tuple through parameter); verify selected current-context, raw flattened ambient config endpoint/CA/reference binding, independently retrieve Kind config and compare endpoint/CA, Docker context/endpoint/container tuple, then frozen Namespace reads for kube-system, baseline owner/UID and target UID. Recheck owner labels of baseline, exact kind/name and nonterminating status for every present Namespace. Return {ok:false,reason:stable nonsecret code} for any mismatch or failed read. No fallback to ambient namespace API. Check snapshot identity/hash again before returning; no success after deadline. Capture command count 12 (current-context 1, common guard 3, raw config 1, Kind config 1, Docker 3, frozen namespaces 3); recheck count 9 (current-context 1, raw config 1, Kind config 1, Docker 3, namespaces 3). Each <=15s, bounded adapter checks monotonic before and after each invocation, timeout floor remaining integer milliseconds, no launch if <=0. Full recheck retains defended <=210s aggregate including filesystem/parse overhead; these command counts do not prove actual latency or justify earlier 60s caps. Capture uses <=210s including snapshot creation, not a separate deadline per command. D02 supplies the scoped synchronous runner below; use it for bounded direct trusted read commands, never mutations. No claim of hard real-time bounds against uninterruptible kernel I/O or arbitrary descendants.

Namespace creation in install.mjs::runWrite: namespace argv adds '-o','json'; validate result.ok, not timedOut/cancelled, strict parsed object kind Namespace, exact name, nonempty UID, nonterminating, expected owner label. mutationAttempted set conservatively at spawn boundary (D02 before invoking mutation; D03 actual attempted flag may distinguish pre-spawn refusal only). On malformed/unknown response retain pending and return possible mutation; never collect to discover UID. Immediately construct bound immutable identity with actual returned UID, custody.advance({phase:'namespace',tuple:bound.tuple}) durably before any subsequent API read; recheck bound identity; then collect and verify prefix/UID. Only mark namespace completed after these checks. Later writes use bound identity, exact own record and guard; no second namespace create. D02 fixture successful namespace response must independently agree with stage namespace UID; wrong/missing response, replacement after response, or failed custody.advance prevents Secret and Helm. Keep legacy pending API until D03, which adds schema2 and verified compare semantics. D04 replaces full classifier and prefix logic, not D02.

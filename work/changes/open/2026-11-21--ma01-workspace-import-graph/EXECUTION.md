# MA01 | executable algorithm

1. Create `scripts/repo-tools/module-graph-core.mjs`: pure graph functions over normalized nodes/edges; compute cycles using Tarjan SCC (stable sorted input/output), classify edges as `runtime`, `type-only`, `reexport`, `dynamic`; aggregate domain owners by first subdir of `packages/application/src/`.
2. Create `scripts/repo-tools/module-graph.mjs`: enumerate package manifests `apps/*/package.json`, `packages/*/package.json`, `tools/*/package.json` and tracked plus untracked nonignored TypeScript source in their `src/` folders. Parse imports/reexports through `typescript.createSourceFile`; resolve relative imports to their file path with `.ts/.tsx/index.ts` candidates and `@offscreen/<pkg>/<subpath>` to a workspace manifest's explicit exports. Report unresolved with source location rather than assuming a dependency exists. Compare source imports with exact `dependencies`/appropriate `devDependencies`, differentiating tests from production source. Ignore irrelevant external imports and TS library types.
3. JSON schema `offscreen.module-graph.v1`: baseline SHA, package nodes/declared edges, source edges, intra-application logical-domain edges, source/public-export mismatches, runtime and type-only SCCs separately, errors and warning classifications. Default human output capped (e.g. 12 edges/hotspots), `--json` full output, optional `--mermaid` for compact graph. No file-writing by default.
4. **Gates:** error for *new* undeclared production workspace imports, nonexistent export subpaths, actual package dependency cycle, or graph parse failure. Existing intra-application SCCs are initially **observations**, not automatic failure; a later approved owner policy records forbidden directions once MA04/MA05 land. No auto-generated Change packets and no assumption of Git branch `main`.
5. Provide `pnpm repo:module-graph:test` for pure fixtures. Avoid new graph framework, third-party cloud service or broad dependency upgrades. All commands run offline.

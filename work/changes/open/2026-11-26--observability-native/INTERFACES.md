## receipt.mjs
export parseEnsureReceipt(result): {ok,state,reasonCode,mutation,completedPhases}; validate command result first, one JSON <=16KiB, schema:1, bool ok, structural state, known reason, mutation none|confirmed|possible, exact unique ordered phase prefix. Successful ensure only exit zero, ready, no pending, either none+empty phases (read-only repeat) or confirmed+all seven. Failure/contradiction/missing receipt never success; uncertain launch/timeout/output loss => possible mutation; no raw detail. Worker output schema1 contains these fields plus pending bool. Plan/status are read-only structural results, not mutation success receipts.
export toObservationReceipt(observation,{allowAbsent=false}): {status,reason,state,pending}; R34 mapping only; PASS iff ready and pending=false, NOT-RUN iff positively verified absent and pending=false and allowAbsent, otherwise FAIL. Stable reason optional-observability-absent/not-installed/ready or sanitized failure code. export evaluateObservationReceipt(result,{allowAbsent=false}): validate subprocess before JSON, reject unknown/missing fields and contradictory combinations, enforce <=16KiB. Only exact default release caller sets allowAbsent. Tests receipt.test.mjs.

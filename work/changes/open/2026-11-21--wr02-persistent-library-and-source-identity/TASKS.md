**Execution:** Cursor. **Integration:** `undertaking/storyteller-workshop`, not `main`. **Status:** planned; WR02 already selected. Follow CHANGE.md; these tasks narrow implementation rather than override its invariants.
**Decision closed for implementation:** choose a **persistent deterministic UTF-8 path trie with fixed hexadecimal-nibble edges (fanout at most 16)** and immutable CAS nodes. Each node has optional leaf record and sorted child hashes. Encode canonical versioned nodes (stable field ordering; omit absent values); hash canonical bytes. This avoids an unratified compressed-radix design session. Uncompressed depth is at most twice normalized UTF-8 path byte length. Enforce path byte/depth caps. If measured size/latency is unacceptable, report benchmark to planner, do NOT silently replace with a flat manifest. A path is one logical key; reject invalid traversal, collisions and ambiguous Unicode normalization, with normalization policy fixed in code and tests.
**Compatibility:** v1 is read-only historical storage, v2 only on explicitly adopted branches. An immutable object hash is identity, not permission; root membership and owner/visibility checks remain required.

## Intended implementation delta

1. Benchmark **no direction vs deterministic style vs same-call optional style** on fixed provider-free model-output fixtures first. Establish an accepted error budget/latency/cost and independently review five passages from one story for continuity.
2. If the owner approves live model evaluation with a real cap, request that authorization separately. **Do not call providers based on this packet alone**. An extra paid ArtDirector agent is not the default.
3. Prefer a tightly bounded optional sidecar in the existing contracted generation output if provider schemas and source settlement support it. Avoid HTML, CSS, freeform URLs, arbitrary style-by-genre or mandatory markup.
4. Validate source-scope, optional fields, color budget/contrast, exact offer IDs, sparse visual emphasis and accepted scene metadata. Rejected directives **must not** fail otherwise valid narration or cause reroll.
5. Use DIR02 exact source publication and log only safe cost/validation receipts. Test same-source non-repaint, five-passage story signature stability, corrupt/missing output and budget refusal.
6. Record adoption decision; if low-quality/costly, mark **Rejected/Parked** while leaving the renderer/deterministic pipeline useful.

## Acceptance: normal and discriminating negative

Normal (only if approved): a single already-budgeted Storyteller operation provides accurate prose and a valid optional mood; the book stays itself while background subtly changes.
Negative: with no output/malformed output/cost cap exhausted, correct passage and offers still publish; no extra charge or plot movement; a stale directive can never recolor a newer passage.

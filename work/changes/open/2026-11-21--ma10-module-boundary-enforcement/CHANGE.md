## Definition of architectural Done

1. **`packages/application` no longer exists as a production or test workspace**: all **112 `packages/application/test/*.mjs` files** are migrated without losing behavioral assertions; obsolete `packages/application/src/{stories,campaign,storyteller,generations,admin,cache}` forwarding code is deleted; old Application manifest/workspace directory removed only after imports/build references reach zero. There are ~136 simple forwarders and 112 existing test files at original baseline. Treat non-TS README/source metadata explicitly.
2. **No repo runtime import of `@offscreen/application`** in `apps/`, `packages/`, `tools/`, `scripts/` (except permanent historical docs, intentional synthetic checker fixtures). No relative file path into `packages/application/dist`. Root workspace/lockfile and build/test scripts stop referring to Application.
3. **Story Engine public subpath surface is explicit and owned**. Replace unconditional `./stories/*`, `./campaign/*`, `./storyteller/*`, `./generations/*` wildcard exports with a mechanically generated **literal allowlist of genuinely external imports** from current host/lab/CLI/test sources and explicit necessary root entrypoints. The allowlist is reviewed once as part of this Change and treated as a stable SDK surface. Do **not** expose arbitrary internal modules just to make deep tests compile; those tests live inside story-engine and can use their own `../dist` output. Preserve legit host composition imports including WR09 public Writer functions. Never narrow API without full caller proof.
4. **Module-level boundary checker** on the existing AST graph distinguishes runtime/reexport/dynamic from type-only, restricts lab imports and authority→Writer runtime implementation backedges, rejects undeclared workspace imports/invalid exported subpaths and material runtime SCCs crossing the authority/Writer boundary. Keep authority-internal collaboration allowed and avoid blanket "zero cycles" rule that would force artificial interfaces.
5. Address **three source-level cycles** found in original relative-file graph by correcting *actual dependency ownership*, not mechanical file splits. The five-module `generations/{index,scripted-openings}` ↔ `storyteller/{dispatch-review,openings,records}` cycle gets one composition-oriented correction. The three-module Writer custody `writer-{child-custody,mission-custody,mission-store}` cycle gets pure shared port/type owner or callback inversion without touching WR09 money/attempt semantics. The authority-internal `campaign/{action-executions,narrative-intent-settlement}` cycle is corrected by extracting shared receipt/event persistence into a narrow authority helper, without a second clock. If any cycle is *type-only*, report and enforce no runtime SCC rather than altering harmless types for a graph metric.
6. Preserve complete playable/storyteller behavior and tests; finalize architecture docs and honest progress; **do not merge into `main` under MA10** (undertaking release gate remains distinct).

**Chosen priority:** real code ownership and import law first, package removal second, source cycles third, API allowlist/graph ratchet after migrations.

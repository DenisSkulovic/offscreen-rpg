# DX12 | decided fail-closed affected selection algorithm

1. Parse flags: required --base REF, optional --head REF default HEAD, --tasks comma-list from build,typecheck,test,test:fast only (default first three), optional --run; no other args. Export decideAffectedScope({changedPaths,dirty,baseIsAncestor,missingRefs}) pure for tests. Spawn git/pnpm with argument arrays and shell:false. No automatic network/package installation.
2. git rev-parse --verify for both commit refs and git merge-base --is-ancestor base head; git diff --name-only --no-renames BASE..HEAD; git status --porcelain --untracked-files=normal checks dirty/untracked. If refs missing/not ancestor, dirty, or git command fails, select FULL, report exact reason. Never assume current main branch.
3. Docs-only via existing isDocsPath -> mode docs-only, zero code tasks and reference docs gates. Root/global inputs from SOURCE-MAP, unknown non-doc path, deleted package manifest, package rename -> mode full. Else source change under apps/packages/tools -> mode affected. An empty clean diff gives zero tasks.
4. For mode affected: spawn pnpm exec turbo run TASKS --affected --dry=json with TURBO_SCM_BASE and TURBO_SCM_HEAD set to exact resolved refs; parse task ids/packages. For mode full: pnpm exec turbo run TASKS --dry=json. When dry-run fails, output is malformed, or an actual code change yields unexpectedly zero selection, fall back to full. Do not claim PASS on an empty task graph.
5. Default prints deterministic plan JSON with base, head, paths, mode, reason, selected task ids/packages and dry-run result, no task execution. On --run, print plan then execute same turbo command without --dry, inheriting child exit code and logs. Do not claim cache hits from dry run selection alone.
6. Keep existing turbo.json outputs unless direct tests prove a missing artifact/input and identify exactly the required globs. Tests with environmental side effects remain separately gated and never become regular cached test tasks. Do not put API keys into global cache env.
7. Unit tests with injected git and pnpm invokers: edit in Story Engine includes its dependent API/Worker/GA/API Integration packages; Web-only excludes unrelated DB-only tasks; docs-only selects no code; root lockfile, missing history, dirty/untracked, non-ancestor, unknown source, deleted package all full; --run absent never executes; malformed JSON full; unexpected flags refused.

**No CI workflow modification.** This is a local developer command with reliable conservative semantics, not a promise of Jenkins/Kubernetes incremental builds.

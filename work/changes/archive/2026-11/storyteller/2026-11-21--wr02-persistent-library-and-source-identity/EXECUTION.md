# WR02 | decided execution design (planner-owned)
**Baseline:** committed code inspected at `f2e0b237`, compatible with [SOURCE-MAP](SOURCE-MAP.md). Code not executed. **Priority:** preserve legacy v1 readers while adding v2 source roots. This design supersedes the vague “choose compressed radix” phrase in CHANGE.md for execution; do not let Cursor choose a tree.

## V2 physical contract
Use **two persistent hexadecimal-nibble tries** beneath one canonical root header:
`offscreen.library-root.v2 = {format, pathsRootHash, idsRootHash}`; `offscreen.library-node.v2 = {format, value:null|entry, children:[{nibble,hash}]}`. A key is UTF-8 NFC-normalized relative logical path for paths trie and lowercase UUID for identity trie. Nibbles traverse encoded bytes, fixed lexical hex order, maximum 16 sorted unique children; canonical JSON and SHA-256 via existing helpers. Paths schema still accepts only safe .md/.json keys; NFC must already equal submitted path (reject rather than silently collapsing two names). IDs tree value is `{documentId,path}`, paths tree value is the existing `documentManifestEntrySchema` plus immutable object hash. **One logical entry, two indexes;** root header hash is the authority-independent identity; no campaignId or branchId in it. Neither a local file path nor hash alone authorizes a read.

Add `putLibraryNode/readLibraryNode` and `putLibraryRoot/readLibraryRoot` to DocumentStore and both Local/S3 adapters, using existing CAS encoding/hashing, 1 MiB object cap and corruption behavior. Write immutable nodes bottom-up; reject mismatch between requested hash and canonical bytes. Empty trie roots are deterministic. Index mutations copy only root→leaf paths; replace/delete/rename must update both indices using same candidate batch; duplicate ID/path, mismatched reverse link or missing referenced object fails. Prefix pagination uses lexicographic UTF-8 normalized paths with {rootHash,prefix,after,pageSize} signed/encoded cursor or validated opaque cursor bound to all four, no reusing across roots. Diff prunes identical child hashes and produces sorted changed keys. Limit per document path to existing logical schema and a declared safe max traversal; no broad scan for point lookup.

## Compatibility and publication
Keep `offscreen.manifest.v1` bytes and v1 readers immutable. Add discriminated `readLibraryRootAny(hash)` adapter keyed by parsed object `format`, never by caller guessed version. v1 old-scene reads must stay on v1. New branch adoption stages root v2 from validated current v1 membership **once**, while root selector remains locked to `story.documentRootHash + documentRootRevision`. In `documents.ts:admit`, derive v2 candidate from expected root, stage all CAS, lock via `lockOwnedStory`, recheck same expected root/revision and operation receipt, then select root+revision/commit/outbox atomically. Retry same operation+request hash returns same root; stale request conflicts. Existing document object envelopes may retain local revision, but citations always include root + object hash + documentId; validate entry hash and membership after owner access.

On fork: new child starts with the selected ancestor **v2 root hash directly**; no new whole-entry manifest and no ancestor previousRootHash chain. Child SQL root revision is a branch-local selector counter (1 for inherited nonempty root), not part of the v2 root identity. v1 ancestral checkpoint fork may continue through verified legacy adapter, but avoid silent history rewrite. Pinned read-only world/start roots are explicit overlays evaluated in deterministic declared mount order; **collision without an explicit override is an error**, not last-wins. `START.md` and `STORY_PROMPT.md` keep their scoped roles. Derived search must check selected root on return.

**Hard stops:** uninspected live Cursor edits conflict with schema; object size/bounded traversal impossible in observed corpus; no rooted authorization; source manifest cannot be faithfully admitted without collision. Stop with concrete counterexample to planner. **No destructive migrations, paid model calls, cluster operations.**

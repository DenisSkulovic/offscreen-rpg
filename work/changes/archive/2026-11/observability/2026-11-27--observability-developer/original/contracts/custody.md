Public contract: acquireCustody(contextName,{mode='exclusive',...existingDeps}) returns a held handle with fd, mode, pendingPath, lockDirectory, cancelled, cancel(), close(); exclusive additionally exposes assertOwnPending(), begin({phase,tuple,operation='ensure',details={}}), advance({phase,tuple,details}), clear(). Shared omits mutation methods. acquireProofCustody is separate as specified below. Never promote a shared handle.

Same context/service lock basename and state root. Separate acquireProofCustody(contextName,deps) uses same private flock implementation with '-observability-proof.lock' suffix, exclusive only, no pending methods or independent mutation authority. Caller acquires platform then proof lock; release reverse order. acquireCustody validates context against actual dev/release profile context names; no path traversal or arbitrary key. Owner-private lockDirectory verified lstat, uid/mode, no symlink, stable dev/ino; open lock O_CREAT|O_NOFOLLOW|O_RDWR 0600, fstat/lstat same inode/dev/nlink=1. Use T04 startOwnedChild('flock',[mode==='shared'?'--shared':'--exclusive','--wait',seconds,'3'],{fds:[lockFd],deadline:lockDeadline,now,signal}) before exposing the handle. lockDeadline=min(caller deadline,phase start+10000); seconds is decimal floor((lockDeadline-now()-killGraceMs)/1s) to millisecond precision, additionally clamped by configured lockWaitSec; no spawn if nonpositive. For two proof-session locks the same 10s phase deadline is shared, not 10s each. Await outcome and require observed close/exit0 plus inode and pending recheck before returning. On ordinary failure close opened parent fd only after observed close; on close-unconfirmed retain fd and fail terminal operation, no lock capability returned, no further writes. Test actual competing flock, pre-abort, timeout and inherited descriptor retention; no synchronous flock wait. Do not unlock with flock --unlock: close only parent fd so inherited open file description remains locked until last child exits. Never unlink lock file. Proof lock no pending record, cannot substitute for platform capability. Shared and proof handles omit begin/advance/assertOwnPending/clear entirely.

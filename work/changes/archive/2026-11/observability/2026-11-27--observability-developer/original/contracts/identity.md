### Scoped synchronous read boundary (T03; T05 migrates remaining consumers)

Add export runObservabilityReadCommand(command,args,{input,timeoutMs=15000}={}) to identity.mjs, implementing existing common runPlatformCommand result shape {ok,status,stdout,stderr,timedOut,missing}. Use spawnSync with shell:false, detached:false, encoding:'utf8', timeout:positive integer, killSignal:'SIGKILL', maxBuffer:8*1024*1024 per stream, windowsHide:true; no retries, no inherited stdin. Reject invalid/expired timeout before launch. Map ETIMEDOUT to timedOut=true, ENOENT to missing=true, any error/signal/nonzero to ok=false (including ENOBUFS); never return partial stdout as usable success. No new generic command API or mutation use. This is a trusted direct executable runner (kubectl/kind/docker/helm/git/cat and other specifically existing read-only commands), not a general descendant or uninterruptible-I/O containment claim. Common commands.mjs remains unchanged; inject this runner into its guard. Existing test deps.run overrides remain explicit. Every phase adapter computes min(commandCap,floor(phaseDeadline-now())) before each call, refuses nonpositive, checks monotonic after result and marks late success failed; phase caps are inclusive. Do not restart the clock or substitute 1ms. The A9 wrapper receives these same external caps; its direct delegated read child must honor shorter parent lifetime via parent-death wrapper, never create a detached group.

T03 owns identity.mjs default runner and install.mjs/artifacts.mjs default read runner routing; T05 migrates inventory.mjs, readiness.mjs and diagnostic-live.mjs observability worker defaults (including injected common guard) and external plan timeout mapping. T06–T11 use this runner for selected synchronous reads, no raw common runPlatformCommand default on observability phase paths. Preserve unrelated shared platform callers. T05 defaultPlatformRunner uses killSignal:'SIGKILL' for exact bounded observability plan invocation only (existing cnpg/postgres behavior unchanged; exact ensure worker exemption retained); mark signal or timeout failed regardless of stdout. Public outer ensure still has separate process-group protection for A9/provisioning. No source changes to unrelated services. Actual read runner tests in identity.test.mjs: real short Node process signals readiness and ignores TERM, timeout SIGKILL returns failure; missing executable, overflow, invalid timeout/no launch, nonzero and late injected result. No cluster. Synchronous calls cannot react to JS AbortSignal until return; check latch before and after every read, never issue a later mutation after cancellation. The per-call cap, outer supervisor and durable fence cover normal trusted binary execution; if OS non-reap or blocked filesystem occurs, do not promise timely cleanup or green. Independent review must accept this bounded-scope limitation.

## Acceptance and negative proof

**Normal:** fresh reader can isolate the governing claim, relevant current source evidence, one normal path and adverse branch without inferring proposed behaviors are already available. **Negative:** A retry starts a second paid call after an ambiguous charged dispatch, or a changed creative profile overrides captured permissions for an existing attempt.

**Stop:** Provider spend, grants and unknown-call recovery remain exactly as selected; no new permission from a documentation example. Unresolved material claim stays Proposed/Blocked, not quietly edited into accepted canon. No gameplay code or infrastructure changes are authorized. Don't start the next packet automatically.

**Completion evidence:** exact before/after semantic equivalence for selected behavior, revised paths#headings, source/revision for all 'implemented' claims, impact-graph review with explicit unchanged reasons, independent adverse reading, `pnpm wiki:health`, `pnpm wiki:change-guard --mode plan` and `--mode close` plus current docs link checker (only if commands actually executed). A green structural result is not sufficient.

## T02 host cadence and durable windows
Anchors collector.py::{MonitoringCollector,_dispatch_due_workers,shutdown}, host.py::{observe_fast_window,rollup_minute,rollup_hour,observe_slow_counters}, storage.py::RecordStore. One dedicated fast sampling worker with absolute monotonic 200ms deadlines; record actual tick time/value at read, skip missed deadlines, no burst catchup. Reuse stats/schema, adapt host function to recorded observations or injected real wait, no repeated reads at window end pretending past. Fast worker owns stream/rollups; separate slow lanes (process/PSS, runtime, health), max one in flight each, bounded commands/output. Serialize append/retention/close under narrow storage lock or bounded single writer queue with explicit dropped coverage; never hold lock across probe/sleep. One session shared with RecordStore and records, actual PID not zero, bounded sanitized error enums not raw exceptions/unbounded gaps. Minute/hour buckets keyed monotonic session preserve sums/count/min/max, partial flush, counter resets, wall jumps. Low memory optional probes suspend explicitly; unknown not healthy. Test slow probe 2s while fast samples continue, no overlap, pulse, missed tick, weighted rollup, stop flush and worker failure.

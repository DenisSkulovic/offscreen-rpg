# Temporary work

**Owns:** open Changes, unaccepted design investigations and short-lived session notes. This is **not** the product/technical bible, source evidence store, or agent rule owner.

| Path | Question |
| --- | --- |
| [changes/](changes/README.md) | Which code-bearing Change, if any, is currently selected? `Current change: none` is valid. Terminal work lives in `archive/`. |
| [designs/](designs/README.md) | Which design investigations are still open, dormant, or retained as historical reference? |
| [sessions/](sessions/README.md) | Short rolling continuity, not a second status or implementation authority. |

**Single-owner routing:** [STATUS.md](../STATUS.md) owns demonstrated implementation/proof; [ROADMAP.md](../ROADMAP.md) owns strategy; [docs/](../docs/README.md) owns ratified product and technical targets; [research/](../research/README.md) owns concluded studies; [evidence/](../evidence/README.md) owns dated proof. `work/changes/README.md` is the **only active selection queue**. No mirrored P5-era queue remains.

**Maintenance:** [repository housekeeping and prevention design](designs/open/repository-housekeeping/README.md) explains how active documents should be routed and retired without deleting unique evidence.

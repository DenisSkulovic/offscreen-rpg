# Storyteller memory and continuity

**Owner (DOC01 P2):** how narrative memory should behave for players. Game-world sparse identity remains under [gameplay continuity](../gameplay/continuity.md); this file owns Storyteller-facing memory expectations and promotion/attachment behavior summarized from storytelling.md.

## Expectations

- A useful detail must survive more than the immediately following choice. Later play receives the **current admitted** version, not obsolete and corrected facts as equally live.
- Earlier passages remain inspectable history; the current canonical record answers what is true now.
- Promotion into concise canonical identity/lore is allowed when continuity value warrants it; passing scenery does not require permanent files.
- Promotion does not automatically create mechanical statistics, inventory, agency or simulation.
- Active-scene attachment of promoted records is bounded and deliberate—not inferred from names in prose.

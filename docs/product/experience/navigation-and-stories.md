# Navigation and stories

**Owns:** the player’s mental map of spaces. **Does not own:** a flows, patterns, or spaces taxonomy.

## Three navigation contexts

1. **Outside a story:** Welcome / Try demo / Your stories / Create story / Account.
2. **Inside a story:** **Now** and **Journal** are the primary labelled navigation. **World** and **You** are contextual detail destinations when meaningful content exists; **Story settings** live in an out-of-fiction menu. These are spaces, not six permanent peer tabs.
3. **During a short task:** one focused layer for selecting intent, inspecting a result, changing course or completing creation. Return to the previous situation without losing the current scene.

A story is never an administrator workspace with peer tabs for Campaign, Activities, Reports, Openings, Presets and Storyteller tasks. Those concepts may exist internally without appearing in player space.

## Surfaces and primary jobs

| Surface | Why someone opens it | Primary behavior | Not |
| --- | --- | --- | --- |
| Welcome | Understand the promise | Try a moment, or continue to stories | Marketing feature grid |
| Stories | Choose which life to return to | Featured story with current state; drafts separated | Table of status codes |
| Create | Decide who/where/what | Foundation → role → direction → review → Start | Gigantic configuration form |
| Now: scene | Perceive and decide | Read passage; choose intention | Chat log / command console |
| Now: ongoing | Understand earned action | Progress, safe controls, expectation | Tick dashboard |
| Now: return | Catch up | Compact digest; continue at present | Infinite activity ledger |
| Journal | Revisit continuity | Overview → passages with source links | “Chapters” |
| World | Explore *known* places/people/threads | Inspect without omniscience or fictional time cost | Mandatory map / global DB |
| You | Inspect relevant self | Actionable status and records | Mandatory humanoid sheet |
| Settings | Change supported preferences | Inspect impact and confirm | Modify past facts / secretly spend |

Follow [target-driven renewal](../../../.agents/rules/target-driven-renewal.md): target → source-grounded gap audit → bounded Change → verified convergence.

No target is an authorization to change application code. Re-evaluate a target explicitly and preserve its rationale before revising a Change plan; do not quietly reinterpret the target to fit the current implementation.

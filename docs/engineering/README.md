For significant portfolio-grade modernization, start from [area-level end states](targets/README.md), then their [source-grounded gap audits](audits/react-next-gap-2026-11-12.md) and only then [bounded implementation Changes](../changes/README.md). The owner-selected [React/Next.js F1–F15 architecture](targets/react-next.md) and [22 scoped implementation packets](../changes/README.md) are complete as **Markdown designs**. Code execution is not selected; all packets remain inactive until a separate Cursor instruction. These are **engineering targets**, not additional game product requirements or permission to code. For cheap Cursor implementations, [web source-adjacent maps](../../apps/web/README.md), [Nest routes](../../apps/api/README.md) and [application owners](../../packages/application/README.md) are the **first stop** after the one Change. [The execution playbook](frontend-execution-playbook.md) owns staged commands and resource economics, not automatic startup context. [Retrieval L0–L4 standard](../../.agents/references/documentation-navigation-standard.md#2026-11-12-explicit-layered-retrieval-contract-for-cheap-coding-agents) governs maintenance.

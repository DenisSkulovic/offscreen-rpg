# SA11 | Reproducible provider-free Storyteller life and quality evaluation harness

**State: Proposed / design-complete 2026-11-14. No code authorization.** Depends SA01 trace and a credible source baseline; useful **before** tuning SA06 as an independent baseline. [SA program](../../storyteller-architecture/implementation-program.md).

## Cursor first-screen brief

> **Outcome:** an executable provider-free story trajectory tests 10–15 meaningful moments across work, interruption, source-backed gift/relationship recall, quiet waiting, alternative creative profiles and nonhuman circumstances, with truthful source/proposal/publication checkpoints. Human prose quality is explicitly unobserved.
>
> **Authority:** [evaluation corpus and stages](../../storyteller-architecture/evaluation-and-playability.md), [constitution](../../storyteller-architecture/vision-and-quality-constitution.md), [historical POC limits](../../engineering/connected-poc-proof.md).

> **Source:** `packages/application/test/live-evaluation.test.mjs`, `long-story-memory-evaluation.test.mjs`, `packages/application/src/storyteller/execution.ts`, `packages/storyteller/src/tasks/result-validation.ts`, `scripts/repo-tools/storyteller-request-audit.mjs`.

## Exact code-bearing outcome

1. Extend the current scenario/packet evaluation harness with deterministic scripted proposals and a versioned output run manifest. It must **not** pretend the scripted proposals were generated by a live model.
2. One trajectory covers a valid accepted long work commitment, partial progress, interruption/hold, a later scene, return to unfinished work, old source-linked gift/favor, and an uninterrupted quiet period. Separate fixtures cover a nonhuman interpretation and materially different captured Storyteller profile, without inventing missing GM actor/autonomy mechanics.
3. At each stage log immutable story/source revision, accepted intent and mechanics, exact model task packet/source handles, investigation policy/rounds, candidate validation, publication/hold, and model provider not run. Expected/acceptable/forbidden source and game effects are independent assertions.
4. Run an existing 200 and 2000-scene memory fixture with objective candidate recall, context assembly, final-inclusion, forbidden evidence and root/fork isolation. Keep retrieval and creativity ratings separate.
5. Add a human-review rubric template for tone, agency, intention, continuity, choice distinctness, personal interest in continuing and cost; fields show **unobserved** until actual humans review real outputs.
6. Reuse Chamber/packet evaluation infrastructure only as needed, not a second universal QA system.

## Acceptance and negative proof

**Positive:** the same saved fixture replays to the same committed canonical state; old gift recipient and source are preserved through 10–15 steps; quiet action costs zero provider requests; two different profiles yield different captured prompt guidance but identical authority.

**Negative:** invented reward, failed item transfer remembered as successful, stale/hidden source, duplicate receipt, wrong-branch memory, universal humanoid inventory in nonhuman fixture, or accidental repeat of a failed unchanged action are detected as objective failures or explicit outstanding GM authority gaps. No mocked “owner likes the story” success.

**Proof:** targeted application/storyteller tests, `pnpm memory:index-benchmark`, existing no-cost packet audit; no provider or real DB by default. If needed, run only against an explicitly permitted disposable DB, never reset the user's ongoing local story. Return exact runner commands, manifest and list of untested real-model/human qualities.

**Exclusions:** paid connected runs (SA12), new GM options, player emotion model, generic LLM judge, mandatory narrative arcs, second agent framework.

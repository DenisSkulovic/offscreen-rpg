## Implementation slices

1. **Schema reuse only:** add strict CommittedActionContextCaptureV1 purpose=consequence/sourceKind=action-receipt to current application-private capture registry. Reuse narrow's actual root, sourcePassages, scene, settings, lease and G helpers; keep pending capture parsing backward-compatible. No unknown JSONB payloads. Extend existing table purpose check only if required, with additive migration and no backfill.
2. **Stage 1 short-lock claim:** receipt already settled and generationId null; do an **unlocked** receipt preflight for storyId, then acquire story lock **before** receipt FOR UPDATE and revalidate. Current code used receipt-first locking; this path must not copy it blindly. Also require matching gameActionExecution.state='settled', same story/offer/baseRevision and preparationGenerationId=NULL (protect existing pending G), no competing campaignConsequence reservation, current narrative/base passage, owner, storyResolution uniqueness, existing storyteller-intent hold. Copy exact receipt plus current committed actor/facts/items/world/commitments/scene/premise/notes/settings/profile/execution/policy and source hashes or inline bodies. No DocumentStore calls. Insert G provisional capture, existing storyResolution with committed-consequence submission, receipt.generationId=G, storyteller hold transfer, existing campaignConsequenceTopic durable wake and view version. On malformed input roll back **preparation only**; keep committed receipt and storyteller-intent hold, surface a typed failed Temporal Activity with no pretend-blocked capture row. **Outbox ACK already happened when Temporal started**; exhausting its bounded Activity retries requires an explicit same-operation operator re-enqueue through existing requestActionNarration/enqueue, not an imaginary un-ACK.
3. **Stage 2 off-lock:** first branch in existing createConsequenceNarration checks companion capture **before** early return for receipt.generationId. Lease G via current narrow bounded policy, close TX, CAS reads by captured hash and verify envelope. Build exact contextInputSchema + resolution from frozen post-settlement receipt and actor state; call prepareAdmittedStorytellerTask(task=consequence) and budget/manifest gate. Short story-lock source/receipt/stale recheck, **including exact SQL passage id/sequence/hash/inline-content/response and actor/world/items/activity/premise/notes/settings/recipe fences**, promote same G to ordinary storyteller task, enqueue existing storytellerTopic. No current SQL read as prompt source.
4. **Stage 3 publication:** for C1 capture, check G/receipt/storyResolution/source root/scene/owner, frozen committed outcome, post-settlement actor digest, settings and mutable model context vs latest under short SQL lock. Existing consequence output/plan admission and staged CAS commit remain authoritative. Hold-to-decision only after successful publish. Stale/blocked is typed and visible, not another paid attempt. **Provisional G status is not an ordinary failed Storyteller task**: read projection must show canRetry=false/recovery operator-or-none until G is promoted, and any visible failure transition must invalidate the version-keyed snapshot cache. Existing retryStoryteller requires kind=storyteller.profiled.v1 plus attemptId; never offer it for provisional G.
5. **Regression:** preserve all old storytellerTaskSchema generations and no-capture rows, the pending capture implementation and all other consequences. No broad formatting, no generalized task/source type.

## Normal and negative proof matrix

| Test | Observable acceptance |
| --- | --- |
| Committed action receipt with generationId null | One G = receipt.generationId = captureId = storyResolution.generationId; same committed mechanical receipt, no second roll; valid consequence scene + offer |
| Two workers / duplicate outbox / post-Stage-1 crash | Exactly one G/hold transfer/promotion/request digest; durable campaignConsequenceTopic re-entry, no lost intent |

| Root/scene/actor/world/items/commitments/settings change during fetch | Stale or blocked before provider dispatch, never publish mismatched current scene |
| Missing/corrupt CAS, oversized capture/context, lease expiry | Typed bounded retry/hold/blocked, no invented prose, no infinite worker replay, no provider request; pre-capture failure can be explicitly requeued using same receipt.operationId after Temporal terminal failure |
| Successful generation then stale source | No controlling publication or paid regeneration; preserve charge identity and required hold/recovery |
| Pre-existing old continuation/opening/report/action task and new pending-capture task | Unchanged decoder/worker/publication, no migration/backfill |
| Provisional held/stale/blocked capture + reload / status API / cache | No false canRetry flag, truthful reason/operator-or-none, stable receipt, state-version/cache bump; normal retryStoryteller is unavailable until promotion |

## Allowlist and non-goals

**Likely source edits:** campaign/narration.ts plus existing narrow capture/materialization path under application/storyteller (actual file names verified before coding); storyteller/context.ts and canonical-knowledge.ts only for reusable bounded readers; storyteller/publication.ts only for purpose fence; existing campaign/holds.ts only if transfer helper needs narrow reuse; **stories/reads.ts, stories/resolution-receipt.ts and campaign/reads.ts only for provisional-capture status/recovery correctness if narrow has not already solved it**, and one minimal owner-scoped operator-only same-operation re-enqueue helper only if existing paths cannot requeue after exhausted Temporal retries; db/schema/storyteller.ts and an **additive** migration only if existing capture table requires a purpose constraint; targeted application integration/unit tests. A narrow worker timeout change may be suggested separately if the existing consequence Activity limit demonstrably prevents bounded materialization.

**Do not edit:** game physics/actions/time/dice/effects/item holders, campaign/action-executions logic, pending capture semantics, interrupted/activity/world consequences, reports, continuation, opening, generic generations, storytellerTaskSchema union, paid provider/route/entitlements, full ENG03 migration, new saga/Temporal workflow, cloud S3 or UI.

# Decision records

**Owns:** consequential *accepted* choices and nontrivial rejected alternatives (ADR-style).  
**Does not own:** full product/technical norms (link out), or open proposals (`work/designs/`).

Format: `D-NNNN--slug.md` with date, acceptance/owner, chosen approach, rejected alternatives, constraints, revisit trigger, supersedes, permanent norm link.

**DOC01 P4:** seed ADRs from clearly accepted ENG/UX/Admin decisions only when owner proof exists. Until then, program `decisions/` folders remain sources—do not invent acceptance by renaming.

# Decision records

Why a consequential trade-off was selected, and when to revisit it. The norm itself lives in the linked product or technical owner. An ADR is not a second copy of that contract.

Only [D-0001](D-0001--modular-engine.md) and [D-0002](D-0002--react-next-client.md) are formal ADRs. A locator row is an index entry. It does not approve a decision. Code that already exists is not an owner-ratified ADR.

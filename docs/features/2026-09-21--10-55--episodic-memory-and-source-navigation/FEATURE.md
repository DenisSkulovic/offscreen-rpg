# Episodic memory and source navigation

Status: Agreed
Approval: Approved as part of the owner's 2026-09-21 long-story memory priority.

## Intended outcome

Long stories retain lived texture, relationships and unresolved consequences without loading every passage or degrading into one generic campaign summary. Compact source-grounded episode, relationship and thread records point back to exact passages and receipts; the Storyteller can navigate from current identities and places to those memories and expand only what the turn needs.

## Representative flow

Mira's identity card links to a prior-visit episode and an open favor. The episode preserves the damaged shutter, awkward tone and source range, while current item state independently says who now holds the key. On return, the context builder selects the current identity/thread cards and episode synopsis. If exact wording matters, the Storyteller reads the cited source section. Correcting the bridge advances the current thread without erasing the earlier warning as a historically attributed claim.

## Scope and boundaries

Includes bounded episode cards, relationship/current-thread cards, source ranges, participants/places/items links, knowledge and authority labels, effective/recorded time, creation/update/retirement rules, coverage watermarks, source navigation and query-focused condensation. Cards are canonical derived records with immutable versions and provenance, but cannot transfer items, change skills or overrule receipts. It avoids mandatory chapter structure, continuous LLM extraction, one recursively rewritten autobiography and summary-on-every-turn costs.

## Acceptance

- A meaningful old relationship/detail is retrieved after 200 noisy scenes and expands to exact source evidence.
- Changed facts distinguish historical truth, current truth, attributed claims and uncertainty.
- Missing/failed card maintenance is visible and raw sources remain discoverable.
- Two same-name identities and forked histories never merge.
- Card creation reuses already-required Storyteller output where practical and has explicit cost/size bounds.
- Ordinary low-value turns need not emit bookkeeping documents.

## Decisions still needed

Tune promotion and segmentation thresholds against the oracle. The first implementation uses explicit admitted links and source ranges, not automatic universal entity extraction.

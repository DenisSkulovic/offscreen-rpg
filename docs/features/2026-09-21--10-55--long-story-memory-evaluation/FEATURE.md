# Long-story memory evaluation corpus

Status: Agreed
Approval: The owner made long-story retrieval the next product-critical program on 2026-09-21 and requested feature folders for the complete implementation route.

## Intended outcome

Developers can tell whether memory changes make a long, mutable story more coherent rather than merely producing plausible prose. A durable provider-free corpus grows from 200 toward 2,000 scenes and asks named questions about exact state, aliases, old callbacks, temporal updates, rumors, private decoys, branches, multi-hop relationships, broad developments and genuine absence. Every case declares expected, acceptable and forbidden evidence.

This is the measurement spine for the other memory features. It prevents selecting BM25, embeddings, rerankers, summaries or graph techniques by fashion or one impressive anecdote.

## Representative flow

A synthetic Greywake history contains two people named Mira, a repaired bridge that supersedes an old warning, a forgotten low-drama favor, a transferred key, a private false possibility and a fork where the city was destroyed. The harness asks both focused and broad questions under fixed context budgets. It records which canonical handles were found, which exact sources reached the final packet, whether stale/private/foreign evidence leaked, and whether the resulting Storyteller answer used the evidence correctly. The abstract-organism contrast must not invent people, money, maps or calendars.

Failures remain diagnostic: retrieval miss, ranking noise, assembly omission and generation misuse are reported separately. An unavailable optional backend skips only its comparison; it cannot turn the baseline green.

## Scope and boundaries

Includes deterministic corpus generation, labelled query/oracle records, scale profiles, retrieval/assembly metrics, optional generation assessment, cost/latency accounting and sanitized artifacts. The initial gate uses structural assertions and scripted outputs; paid judges and provider calls require separate authorization. It does not choose the retrieval backend or treat synthetic prose quality as player acceptance.

## Acceptance

- Reproducible 200-scene corpus with stable identities, sources, revisions, visibility, fictional time and branches.
- At least twelve query classes, including updates, abstention, low-drama recall and abstract-world contrast.
- Retrieval, assembly and generation failures are separable in one compact report.
- Every memory implementation can run against the same fixed candidate/read/byte budget.
- A 2,000-scene scale profile proves bounded query work or exposes the precise scaling blocker.

## Decisions still needed

Numerical quality thresholds will be fixed after the current linear baseline is measured; they must not be chosen to bless it.

# Repository discovery and maintenance

Status: Implementing
Approval: The owner explicitly requested autonomous project rediscovery and substantial improvements to agent efficiency, documentation layers and maintenance on 2026-10-23.

## Intended outcome

A returning owner or fresh agent can explain the product, implemented loop, strongest evidence, current limitation and next action without reading large implementation files or every feature plan. Deeper questions have a clear authoritative owner. This changes repository navigation and maintenance, not gameplay.

## Representative flow

Read the root overview, run the repository brief, choose one question in the documentation map, then open its contract and package route. The brief follows the actual current plan and fails visibly if that route disappears. A maintainer updates the owning explanation and affected summaries in the same slice; historical evidence remains dated and distinct from current capability.

## Scope and boundaries

Correct stale entry points and evidence summaries; add a layered documentation map; repair the read-only brief; reduce unconditional instruction load through explicit task triggers; reconcile misleading package guides and checkpoints. Preserve spending, authority, lifecycle and verification policy. No provider calls, infrastructure startup, gameplay changes or model tuning. Do not erase unfinished feature requirements to simplify the index.

## Acceptance

- Overview answers what the game is, how its loop works and where demonstrated behavior stops.
- Brief includes the current next action and selected plan without hard-coded historical feature paths or silent missing sections.
- Readers can route product, mechanics/time, narrative/memory, execution/cost, presentation and evidence questions without loading every library.
- Current summaries agree with inspected source and saved local evidence; dates and limitations are explicit.
- Maintenance rules keep one owner per decision, conditional detail and small resumable checkpoints.
- Review the changed links and exercise the brief's success and missing-route behavior; do not run gameplay suites for documentation work.

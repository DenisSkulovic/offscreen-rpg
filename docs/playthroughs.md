# Playthroughs

Stub — to write together, following what players see, do and experience over real time. Examples explore the product; they do not automatically establish requirements or software entities.

Starting example: arrive at the website, create a story, set out as a wizard, encounter a goblin offering fruit, become trapped inside an apple, wait and face a new danger. Use this to examine creation, agency, immediate consequences and long waits. Also work through how the experience changes when a friend participates.

The flow, interface and behavior are still to be discussed.

# Agent Core

`@offscreen/agent-core` is the selected E1 grouped workspace for generic mission contracts and, in later Changes, Workflow-safe execution. Selected meaning stays in the [Agent Core technical contract](../../../docs/technical/platform/agent-core.md#concrete-mission-contract) and the [package map](../../README.md). This package does not own story fiction, storage adapters, billing, or provider wire protocols.

## Current source

The public root export is serializable `AgentDefinitionV1`, `MissionV1`, and `MissionOutcomeV1` plus `missionWorkflowId`, which returns `agent-core-e1-${missionId}`. There is no Worker, client, or model import in that closure. `src/workflow.ts` exports `executeMission` and the trusted binding types. It runs one `generateText` call through `TemporalLanguageModel` (`maximumAttempts: 1`, 10s start-to-close, 2s heartbeat, wait-for-cancellation). Sticky denial, tool failure, and unfinished calls stop further generation. Cancellation is rethrown. The Workflow log records the workflow id and terminal counts only. Native qualification, including invalid-tool and replay proof, remains **NOT RUN** and belongs to AC08.

Internal admission is `admitMission` and `assembleContext`. `createMissionLedger` / `resolveOutcome` keep a per-run step and tool budget: denial outranks limit, then failure, then a normal nonempty stop. These modules do not import Temporal or the AI SDK. Requested tools are copied and never expanded. The fixture envelope is 1–3 steps, 2 tool attempts, and 4096 UTF-16 code units of instructions or input.

`selectCapabilities` returns only names present in the static binding list, in request order. Duplicate or illegal registry names throw `invalid-registry`. A name outside that list throws `tool-not-allowed`. `validateToolInput` rejects non-JSON and arguments over 1024 UTF-16 code units before schema parsing. `createSdkTools` builds SDK tools only for that selected list. It denies a bad argument, reserves a tool attempt before dispatch, and records `tool-failed` when the synthetic Activity result is not a string of at most 4096 units. Cancellation is not recorded as an ordinary failure. There is no dynamic function lookup and no real tool.

`pnpm --filter @offscreen/agent-core build` and `typecheck` compile `src`. `test` runs `node --test test/*.test.mjs` and must stay offline. Admission, limit, and registry tests import `dist`. `qualify` is explicit (`node test/qualification.mjs`) and is never invoked by `test`. Test fixtures live under `test/fixtures/` and are not a public export. They provide two immutable definitions, a conversation-driven `e1-synthetic` model, and a guarded synthetic tool Activity. The model plugin download hook rejects every request with `download-disabled`. There is no real provider, network, file, or credential access. A local `tsc --noEmit` passed for the admission source. Focused `node --test test/fixtures.test.mjs` passed on the AC07 branch. Package `build`, the admission/limit tests, and joint proof are **NOT RUN**. AC08 still owns native qualification, including the ungranted-tool case. AC-M03 and AC-M04 remain open until that qualification.
